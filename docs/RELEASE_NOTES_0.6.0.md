# v0.6.0 — 独立回放与录像分类

技术验证预发布，最低 Android 10，支持 arm64-v8a / x86_64。使用项目已有的固定测试签名，可覆盖安装相同签名的旧版。

- 独立回放页面：暂停/恢复、0.5/1/1.5/2 倍速、进度显示与拖动、横竖屏；不停止或重启运行中的录像任务。
- 录像区分手动、活动及混合来源，提供分类筛选。两种来源重叠时共用录像连接。
- 文件按分段录制时间范围命名，例如 `20261105_103000-20261105_103500_手动.mp4`；跨日保留完整日期，重名追加序号，导出相册保持同名。
- 活动通知独立于录像状态通知，不再被保存或录像进度消息覆盖；通知权限和渠道关闭时显示提示。
- 数据库无损迁移至版本 3，旧录像及其导出 URI 保留；旧文件缺乏可靠元数据时显示来源/时间未知，不批量改名。

本地构建与 lint 通过；22 项核心单元测试、6 项数据库检查，以及回放隔离、旋转实际出帧、原生分段、来源累计、导出命名和异常恢复检查通过。GitHub Actions 另行构建并校验随本版本发布的固定签名 APK。

**已知限制：** 活动通知端到端测试在 Apple Silicon 主机的 ARM64 Android 模拟器上因现有 MediaPipe 原生 `RDSVL` 指令崩溃而受阻，不能视为该功能验收通过。真实手机活动提醒、真实摄像机和锁屏验收仍未完成。本包使用测试签名，并非生产发布版本。

详见[实现与测试报告](https://github.com/JinzhongYe/RTSPMonitor/blob/v0.6.0/docs/PLAYBACK_RECORDING_UPDATE.md)。附件提供 APK、签名信息和 SHA-256 校验文件。
