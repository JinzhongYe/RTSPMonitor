# v0.7.0 — 回放与录像浏览布局优化

技术验证预发布，最低 Android 10，支持 arm64-v8a / x86_64，沿用 GitHub 旧版固定测试签名。

- 固定播放器＋日期选择＋来源筛选，录像按小时分组，以缩略图网格浏览。
- 普通竖屏三列，窄屏或大字体两列；当前片段高亮，支持前后 10 秒、倍速、进度拖动与横屏全屏。
- 导出与删除集中在“更多”菜单，监控页改为录像数量及浏览入口。切换回放、导出和删除已完成片段不会停止运行中的录像任务。
- 后台缩略图提取最多两个并发任务，采用私有磁盘缓存及 12 MiB 内存缓存；删除时清理缓存。
- 保留原有录制、检测、时间范围命名及数据库结构；没有新增云录像、AI 搜索或全天跨片段时间轴。

本地构建与 lint 通过，24 项单元测试通过；已检查正常宽度、320dp 窄屏、1.4 倍字体及实际点击横屏的布局。回放/导出/删除期间的录像隔离与重建后实际出帧检查通过。发布 APK 另经 GitHub Actions 构建检查和固定密钥签名。

截图使用合成录像，不是真实摄像机画面；用户参考照片没有上传。真实手机、大规模录像库及高负载仍待验收，原有 MediaPipe ARM64 模拟器崩溃限制没有在本次修复。
