# v0.5.0 自动监控测试版

## 新功能

- 自动监控开关首次手动开启，之后记住选择。手机本地检测人形或明显画面变化，触发自动录像与活动通知；连续无活动 30 秒后停止。同一事件只提醒一次，不上传画面。
- 手动录像和自动录像共用一个录像器。停止手动录像不会关闭自动监控，自动事件结束也不会停止仍在进行的手动录像。
- 新录像先保存在应用内部，完成后点击“保存到相册”导出到 `DCIM/RTSPMonitor/`。重复导出不生成重复副本。
- 按 Home、返回桌面或灭屏后保持后台任务。再次打开应用自动恢复实时预览，页面重建不停止检测或录像。
- 保留约五分钟分段、原始视频编码及断线重连；旧版录像索引自动迁移，原有相册录像保留。

## 安装与数据

沿用 v0.4.0 固定测试签名，可覆盖升级。Android 10 及以上，arm64-v8a / x86_64；附件包含 APK、SHA-256 校验和和签名信息。

**卸载会删除应用内部尚未导出的录像，请先保存到相册。** 已导出的相册副本独立保留。密码仍需自行输入并在本机加密保存，不包含在 APK 中。

## 验证

- 构建、单元测试、Lint、Python 检查，以及模拟器上的模型、迁移和保存导出检查。
- 本地 Android 16 模拟器连接真实 H.265 摄像头，灭屏录像超过十分钟，生成约 304 秒、300 秒、47 秒三段视频，返回后监控与预览正常。
- 使用公开人物测试画面验证人形识别、自动触发、后台自动收尾、通知去重及手动/自动录像共存。实测静止尾段约 31.4 秒，包含采样和收尾延迟。
- 验证应用内视频回放、相册导出，以及销毁并重建页面后保持后台运行。

你的实体手机和厂商省电策略尚未验收；识别可能误报或漏报，持续检测会增加耗电。强制停止或重启期间不保证录像连续。当前摄像头的 G.711 音频会被忽略，保存的视频无此音轨。
