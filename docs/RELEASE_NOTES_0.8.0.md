# v0.8.0 — 可调活动阈值与手动录像分段

技术验证预发布，最低Android10，arm64-v8a/x86_64；沿用GitHub旧版固定测试签名。

- 新增“检测与录像设置”，可调人形置信分、变化面积和亮度差，支持恢复默认、取消及本机持久化，保存后即时生效。
- 手动录像每段可设1～60分钟；活动录像仍为5分钟，重叠期间手动优先。不会按此时长停止总录像，而是在达到上限后的下一关键帧切换文件。
- 运行中修改参数、手动/活动模式切换不重启录像连接；重连后使用当前配置。既有文件命名、来源分类及独立回放保留。

本地构建、lint与28项单元测试通过，设置持久化、运行中参数更新和原生动态分段有仪器测试证据。2/4秒分段是加速测试，不代表分钟级长测。发布包另经GitHub Actions检查与固定密钥签名。

真实手机灵敏度、误报率和锁屏仍待验收；现有MediaPipe ARM64模拟器SIGILL限制未修复。本包仍为测试签名预发布版本。
