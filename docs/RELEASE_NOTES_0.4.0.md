## 更新内容

- 改为单摄像头监控台，整理实时预览、中文连接状态、录像控制与录像列表。
- 配置移到设置窗口，移除并发配额和 sout 实验入口。
- 默认地址为 `rtsp://192.168.0.210:554/stream1`，用户名 `admin`，默认 TCP。首次使用请在手机输入密码；密码不包含在源码或 APK 中。
- 设置使用 Android Keystore 加密保存；修改设置前会停止预览及录像并完成收尾。
- 旧版有多个设备时可选择使用的一路，其他设备记录和历史录像保留。删除录像增加确认。

## 安装说明

这是 Debug 签名测试版，支持 Android 10 及以上，包含 arm64-v8a / x86_64。

本版采用新的固定测试签名，与 v0.3-spike 不同，不能直接覆盖安装。请先备份所需录像再卸载旧版；卸载会清除设备配置、凭据及应用私有临时录像。首次安装后重新输入摄像头密码。后续测试版将沿用此签名。

下载 APK 后可使用随附的 `SHA256SUMS.txt` 核对文件；`apk-signature.txt` 记录签名证书。
